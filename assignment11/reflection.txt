1.Reflect on the differences between static and interactive visualizations.

A.	The differences between static and interactive visualizations are that in static, the data are fixed images, and the user can't interact with the visualized data, like zooming in on a particular section of data, etc.
 	And in interactive visualization, users have more flexibility, like zooming in on a particular section, selecting, hovering, filtering, and grouping data for more in-depth data analysis.


2.Write a short paragraph discussing the advantages of using dashboards for real-time data exploration.

A.	Dashboards are a powerful tool to explore real-time data because users can organize and visualize data formats that update dynamically. With that, the user can monitor changes, identify trends, and other things easily. 
	Dashboards can combine multiple visualizations in one place,which helps to compare different aspects of data. They help in improving decision-making by making data more accessible.


3.Explain how interactive tools like Plotly can improve data communication in professional settings.

A.	Interactive tools like Plotly improve data communication in professional settings in many ways. Interactive tools like Plotly make data more accessible, engaging, and easier to interpret.
	Rather than just relying on static charts, here users can interact with data by visualizing it by zooming, hovering over data points, and filtering information to focus on specific details.
	It helps everyone understand trends, patterns, etc. As a result, it enhances decision-making by allowing users to explore data dynamically.
